# Security policy

Security issues in this project are taken seriously. If you believe you have found a vulnerability, please report it responsibly rather than disclosing it publicly before maintainers have had a chance to address it.

## Reporting a vulnerability

- Use the private security-advisory feature on GitHub (Security → Advisories) when available.
- Otherwise, contact the repository owner directly (see the GitHub profile for contact details).
- Include a clear description, steps to reproduce, affected versions, and any suggested remediation.

## Expectations

- You will receive an acknowledgement as soon as possible.
- The maintainer will work to validate, fix, and disclose the issue in a coordinated way.
- Please avoid publishing an unpatched vulnerability before a fix is released.

Thank you for helping keep this project safe.
